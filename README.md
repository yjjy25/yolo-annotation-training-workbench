# YOLO 标注训练一体化工具 v0.7

模型转换与量化：打开项目后，进入侧栏“模型转换与量化”，或点击已训练模型旁的“转换 / 量化”。支持 YOLO PT → ONNX FP32 / FP16 / INT8，以及 TorchScript FP32。INT8 需要代表性真实图片进行静态 QDQ 校准，无需手写 YAML；FP16 需要目标设备支持。输出位于项目 `exports/<独立任务目录>`，包含模型和可追溯的 `export.json`，不覆盖原权重。转换在独立进程运行，可查看日志或停止。当前不包含 TensorRT / OpenVINO 导出；转换成功不代表量化后的精度和速度已经通过验证。

基于完整 X-AnyLabeling 4.1.3 源码扩展，使用 Electron 外壳。标注、视频追踪、模型验证和训练在同一个窗口完成。

**v0.7 新增 WiFi 摄像头采集与 MaixCAM 导出，模型结构页改为 3D 张量视图并开放部分顶层卷积的填充/步幅编辑；训练快照改为硬链接共享图片，重复训练不再占用整批副本。提供 Windows x64 与 Ubuntu amd64 自带运行库安装包和对应源码。**

## 这次更新

- **WiFi 摄像头采集**：工作台经局域网连接 MaixCAM / MaixCAM2 板端脚本，实时预览、单张拍照或按间隔连续采集，原始 JPG 直接进入当前项目 `images`，采完即可标注。断线或入库失败会停止并保留照片，可重试入库。
- **MaixCAM / Pro 导出**：标准 YOLO26 Detect 权重导出 ONNX FP32（默认 320×224），显式保留 one2one 分支并检查 MaixHub 六个检测节点与输入尺寸，附类别表和量化说明；其他模型会被明确拒绝。
- **看模型流程**：按“提取图片特征 → 融合信息 → 输出位置和类别”查看模型真实结构；结构页默认是可旋转、缩放和选择的 3D 张量视图，保留 2D 连线，可逐级进入重复块、卷积组和独立算子。
- **看懂检测头**：先选“框在哪里”或“是什么目标”，再选输入尺寸和内部处理层；不再显示几十条近似的完整源码路径。
- **调整参数**：可修改符合规则的卷积核、池化核和单层激活函数；YOLOv8n/s、YOLO11n 的顶层卷积还可单独设置 padding / stride，并定位首个尺寸冲突。
- **核对修改**：显示实测输入输出与修改前后对比，支持撤销、恢复默认结构、检查保存和载入历史修订；几何修改会重新校准检测步长后才允许保存。
- **用于训练**：修订经前向、损失和反向检查后，可在工作台里从零训练；记录结构和源码身份，训练重建时回放修改。
- **训练权重**：训练页标明内置模型是否已缓存，可勾选允许从 GitHub 下载缺失权重并显示进度；也支持“从零训练”离线生成结构。
- **数据分组**：默认按图片划分训练/验证集，至少两张已确认图片即可开始；可勾选按来源与相似图片整组划分，减少训练和验证混入同一来源。
- **省磁盘**：数据集快照改为内容寻址硬链接，以后每次训练只新增标注文件，不再重复复制整批图片；旧项目可用 `scripts/compact_snapshots.py` 预演并合并。

当前模型编辑限于**目标检测、固定连接、已开放参数和随机初始化训练**。填充/步幅编辑只对 YOLOv8n/s、YOLO11n 顶层卷积开放，详见 [几何编辑说明](文档/模型几何编辑_开发说明.md)。自由增删重连、自动适配、预训练迁移及精度收益比较尚未实现；检查通过只代表程序链路可运行。

## 下载与启动

**v0.7 下载**：[GitHub 版本页](https://github.com/yjjy25/yolo-annotation-training-workbench/releases/tag/v0.7)。安装包下载、分卷合并与升级方法见 [安装说明](文档/v0.7_安装说明.md)。

- Windows 10/11 x64：[下载 Windows 离线安装包分卷](https://github.com/yjjy25/yolo-annotation-training-workbench/releases/tag/v0.7)。运行后选择位置并解压安装，可创建桌面快捷方式。包含独立 Python、Electron、CPU/CUDA 训练组件，无需另装 Python。程序可整体移动，移动前先退出。
- Ubuntu x86_64：[下载 Ubuntu DEB 安装包分卷](https://github.com/yjjy25/yolo-annotation-training-workbench/releases/tag/v0.7)。通过软件安装器打开；也可执行 `sudo apt install ./AnnotationWorkbench-0.7.0-Ubuntu-amd64.deb`。安装后在应用菜单找到“标注训练工作台”。系统图形库缺失时由 apt 补齐。
- 源码运行：先按下方“源码开发”准备环境，再双击 `双击启动.vbs` 或运行 `bash start.sh`。

完整离线包超过 GitHub 单文件限制，需要先合并分卷：

- Windows：从 Release 下载 Windows 的两个 `.part` 文件、`parts.json` 和 `join.ps1`，放在同一目录，运行 `powershell -ExecutionPolicy Bypass -File .\join.ps1`。
- Ubuntu：下载 Ubuntu 的两个 `.part` 文件、对应的 `.parts.sha256`、`SHA256SUMS.txt` 和 `join.sh`，放在同一目录，运行 `bash join.sh Ubuntu`。

脚本自动核对 SHA256；合并后的 EXE/DEB 可直接安装，无需另装 Python。下载文件和合并文件会同时占用空间。

Windows 和 Ubuntu 是不同文件，不能互相替代。离线包体积较大，包含 CPU/GPU 训练依赖；使用 GPU 仍须有兼容的 NVIDIA 驱动。发布包为未签名开发版。

## 同一张图可以有多个类别、多个对象

新建项目时填写多个类别，例如 `猫, 狗` 或 `站立, 趴卧`，逗号分隔。标注画布右侧可通过类别按钮、下拉框或数字键 1–9 切换。

1. 选择“猫”，为猫画框；再选择“狗”，为狗画框。两种标签同时保留在同一张图中。
2. 姿态项目可选择“站立”标一只狗，再选择“趴卧”标另一只狗。每个对象有独立目标框、类别、骨点和实例分组。
3. 修改已有对象的类别：先选中该对象，选择新类别，再点“修改选中对象的类别”。
4. 姿态类别与骨点名称分别设置：类别可以是“站立/趴卧”，骨点可以是“鼻尖/膝盖”。

同一姿态项目使用同一套骨点顺序，可选人17、狗24或通用自定义骨点。需要不同骨点定义时分别建项目，避免训练时骨点含义混乱。

## 新手最短流程

1. 新建项目：**先选任务，再选要画的图形，最后填写类别并导入图片**。多个类别用英文逗号 `,` 或中文逗号 `，` 分隔，例如 `猫, 狗`。导入使用副本，原始数据保留。
2. 标注：检测画矩形，分割勾轮廓，姿态画框后放置或顺序点选骨点，旋转框可拖动旋转手柄，分类为整张图选类别。快捷键：↑/↓ 或 A/D 切图，Enter 确认并下一张，1–9 换类别，V 选择，R 画图，Ctrl+S 保存，Ctrl+Z 撤销，Ctrl+1…6 切换工作区。
3. “保存草稿”只保存编辑；“确认无误，下一张”表示通过人工审查，可用于内置训练页。
4. 点击“模型训练”，选择初始模型、CPU/GPU 和参数，点击“开始训练”。训练状态显示第几轮 / 总轮数、当前损失与 mAP；完成后“训练结果”区展示训练曲线、混淆矩阵和验证集预测示例，可点开大图。
5. 点击“模型验证”，选择本项目训练出的模型，用训练时冻结的验证集评估，得到 mAP、精确率、召回率与结果图，历史记录可对比。
6. 批量生成候选后进入人工审查，按需接纳、微调并再次确认。

## 三种标注方式可切换

| 方式 | 用法 |
| --- | --- |
| 人工标注 | 不需要模型，直接画框、轮廓或点骨点 |
| 预训练模型预标注 | 选已有模型生成全部图片候选，然后人工修正 |
| 少量标注后训练 | 先标注并确认一部分数据，训练专用模型，再批量标注并审查 |

生成候选不直接覆盖正式标注；接纳前检查文件是否已变化并保留备份。切换方式不会清空已有标签。

狗24预设是骨点定义，不是已训练的狗姿态模型。狗和自定义骨架需使用匹配的模型；可以用人体姿态权重初始化训练，再用生成的专用模型预标注。

## 训练与高级功能

内置训练页支持检测、分割、姿态、旋转框、分类；可填写模型、设备、轮数、批大小、图片尺寸、学习率、早停、Workers 和 AMP。提供 YOLOv8、YOLO11、YOLO26 及本地权重入口；具体架构由当前 Ultralytics 支持情况决定，不表示所有型号均已验证。

简洁训练页使用 SGD，填写的初始学习率会实际生效。AMP 默认关闭；开启后框架可能首次下载额外的检查模型。其他优化器可在高级训练页选择。

训练只读取已人工确认的数据，冻结为独立快照，结果保存在项目 `runs`。默认按图片划分训练/验证集，至少需要两张已确认图片。可在数据页勾选“按来源与相似图片整组划分”；开启后同源视频和已识别的重复图片不跨集合，实际数量可能偏离目标。首次选用未缓存的模型仍需联网下载。

“高级标注”“交互分割 / 更多模型”“高级参数与模型导出”均显示在本工具内，保留原版菜单与控件。“关闭当前面板”取消弹窗，保存后“返回简洁标注”。高级训练保留原版自选数据集配置，使用时核对数据和划分。

浅色、深色与跟随系统会同时作用到工作台界面和高级标注里的原版工具，选择结果重启后保留。在 200% 缩放屏幕上，高级标注按显示缩放渲染，不会出现画面忽大忽小或整体发虚。

右上角“×”可退出，新建表单和高级面板不会挡住关闭按钮。退出前尝试保存草稿并保留恢复材料；运行中任务会询问是否停止。恢复材料中的未完成轮廓点目前需要人工处理，尚无一键恢复界面。

| 内容 | 位置 |

## 源码开发与 GitHub 发布

使用 Python 3.12、Node.js 22.12+ 和 npm。Windows 源码环境：运行 `powershell -ExecutionPolicy Bypass -File setup-windows.ps1`（可加 `-Device gpu`），再双击启动脚本或执行 `npm --prefix desktop start`。Ubuntu：`bash setup-linux.sh cpu`，再 `bash start.sh`。准备环境会联网下载依赖，仅在项目内创建环境；GPU 需要兼容驱动。源码不附带预训练权重，首次选用模型需联网。

便携离线二进制包使用 `.packaging/构建说明.md` 的独立构建流程，不能直接把源码 ZIP 改名为 EXE。Windows 程序整体移动前请退出，项目及设置位于程序旁“工作台数据”；DEB 安装是系统安装，项目及设置位于用户配置目录。

上传 GitHub 应使用已检查的 Git 文件清单，或修正并验收后的 `.packaging/package_source.py` 干净源码导出，保留 LICENSE、THIRD_PARTY_NOTICES.md 和上游版权。个人项目、备份、运行库、权重和大型发行包已排除；不要直接上传整个开发目录。安装包放在 Releases。完整版超过 GitHub 单个 Release 文件 2 GiB 限制，使用 `发行包/GitHub-Releases` 中的分卷、parts.json 和 join.py；用户下载同一平台的全部分卷及校验清单后运行 `powershell -ExecutionPolicy Bypass -File .\join.ps1` 或 `bash join.sh Ubuntu`（也提供 Python 重组脚本），将验证 SHA256 并合成原安装包。

v0.7 的发布范围与验证记录见 [发布说明](文档/v0.7_发布说明.md)。旧 v0.6、v0.5.2 安装包的历史验证范围见各自的发布检查记录。已在现有 Windows 与 WSLg 环境验证的内容不代表全部模型、硬件和 Linux 发行版均已验收。

## 视频与姿态标注扩展（源码）

支持视频抽帧后逐帧标注、顺序点选时直接拖动已有骨点、跳过与遮挡快捷键、模板左右镜像/上下反转，以及项目照片示例与编号点位规范。使用方法见 [姿态标注规范](文档/姿态标注规范.md)。这些功能已纳入 0.5.0。

保存审核时复用缩略图、预读下一张图片，并将视频审核后的列表同步移出切图等待流程，减少黑屏和等待。720×1280 图片副本的保存切图实测及验证范围见 [保存切图性能修复](文档/保存切图性能修复_20261018.md)。这些修复已纳入 0.5.0。
