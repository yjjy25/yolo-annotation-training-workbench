# v0.6 安装与升级

应用版本为 0.6.0，GitHub 发布标签为 v0.6。Windows 与 Ubuntu 安装包分开提供，不能混用。

## Windows 10/11 x64

下载 Windows 的全部分卷、`parts.json` 和 `join.ps1`，放在同一目录。运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\join.ps1 Windows
```

校验并合并后，运行 `AnnotationWorkbench-0.6.0-Windows-x64-CPU-GPU.exe`，选择新的安装目录，可创建桌面快捷方式。安装包包含 Python、Electron 与 CPU/CUDA 训练依赖，不需要另装 Python；GPU 仍需兼容的 NVIDIA 显卡驱动。程序为未签名开发版。

升级前先保存并退出旧版。建议安装到新目录，通过“打开项目”继续使用原项目，不删除旧程序旁的“工作台数据”。

## Ubuntu 22.04+ x86_64

下载 Ubuntu 的全部分卷、`parts.json` 和 `join.sh`，放在同一目录，运行：

```bash
bash join.sh Ubuntu
sudo apt install ./AnnotationWorkbench-0.6.0-Ubuntu-amd64.deb
```

合并过程会检查 SHA256。安装后从应用菜单打开“标注训练工作台”。应用运行库自带 Python、Electron 和训练依赖；系统图形库由 apt 按包声明补齐。用户数据位于 `~/.config/AnnotationTrainingWorkbench`，项目仍保存在你选择的位置。

## 从模型设计开始

1. 新建或打开目标检测项目，点击“模型结构设计”，选择模型并加载结构。
2. 左侧点击最后的检测头，右侧先选“框在哪里”或“是什么目标”。
3. 选择输入特征尺寸、处理层，再选择卷积范围或响应方式。源码和只读信息在“技术详情”中。
4. 应用修改后点击“检查并保存修订”。通过后可用于工作台内的从零训练。

检查通过只代表当前输入尺寸的程序链路可运行，不代表识别精度提高。效果需要使用真实数据训练和验证。当前未开放自由增删重连、独立填充/步幅设置及预训练权重迁移。

## 下载与故障排查

只下载需要的平台分卷。完整安装包及分卷会同时占用空间，请预留足够空间。保留校验清单，不把源码 ZIP 当作安装包。

如无法启动，请保留错误提示与启动日志。Windows 日志在程序旁“工作台数据”；Ubuntu 在 `~/.config/AnnotationTrainingWorkbench`。不要删除项目中的图片、标注或训练结果来尝试修复程序。
