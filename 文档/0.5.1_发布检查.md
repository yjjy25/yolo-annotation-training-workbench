# 0.5.1 发布检查

构建日期：2026-10-19。版本功能见 CHANGELOG.md；

## 备份与回归

源码和用户项目在变更版本前已备份，6259 个文件逐项 SHA256 与 ZIP CRC 核对通过，约 538 MB。正式源码和安装包排除个人项目、备份及本机缓存。

- Python 工作流与训练回归：22 个模块，共 216 项通过。视频模块出现过测试全部通过但进程退出异常；训练停止模块在沙箱内失败。两个模块分别在正常本机权限下复核，3 项与 6 项均通过，未改动断言。
- JavaScript 语法与原有画布边缘、姿态、异步保存、图片缓存、划分、进度回归通过。
- Windows 0.5.1 包内独立运行库实测四种导出组合：ONNX FP32、FP16、INT8，TorchScript FP32；18 项流程验收通过，原始 PT 的 SHA256 不变。
- 来源精度读取与说明弹窗已在实际 Electron 页面验证。测试用 YOLOv8n 存储精度为 FP16，未依据文件后缀猜测。

## 验证边界

用于流程验收的少量合成校准图片不能证明真实任务准确率。本轮尚未完成真实数据量化精度对比、目标 GPU FP16 推理、多 GPU 和所有模型任务组合的实机验收。Ubuntu 标准桌面和默认沙箱尚未实机验证；WSLg 使用隔离图形依赖及 --no-sandbox --disable-gpu。

## 包体与发布

Windows 全部 ZIP CRC、Ubuntu DEB 流式读取与 Linux chrome-sandbox 权限检查通过；两个平台各 1493 个应用源码、字体和随包说明文件与当前源码一致，个人项目及程序用户数据未混入归档。

真实 Windows EXE 使用安装器 --extract-only 解压成功。解压后的程序完成四种导出组合的 18 项验收，以及 NVIDIA GPU 检测/姿态标注、训练、批量候选流程；人工标注哈希保持不变。

Ubuntu 包内独立 Python/Electron 在现有 WSLg 完成四种导出组合的 18 项验收。本轮未重新验证标准桌面安装或 Linux GPU。

本地验收记录：`.packaging/checks-0.5.1/results-verified.json`、`.packaging/qa-extracted-windows-051-export/report.json`、`.packaging/qa-extracted-windows-051-gpu/report.json`、`.packaging/qa-linux-051-model-export/report.json`。这些验收使用隔离的合成流程数据，不能当成真实识别效果评测。
