## 交付目标与实现

| 用户要求 | 本轮实现 |
| --- | --- |
| 直接集成工具，无需另开软件 | 主画布、训练、候选审查为 Electron 页面；原版高级 Qt 控件通过本地渲染及输入接入层显示在高级标注页。无外部服务、端口或登录步骤。 |
| 无法退出 | 统一标题栏退出流程。新建表单不再拦住关闭按钮；关闭前保留草稿，通知后台收尾，再清理本应用拥有的进程。重复点击关闭不会重复打开退出确认。 |
| 标签含义清楚，新手能用 | 区分任务、类别、图形和实例；图形名称中文化，人体骨点使用中文显示名称。“添加类别”“保存草稿”“确认无误，下一张”分别表达不同操作。 |
| 人和狗预设、通用骨点 | 保留人17、狗24和自定义模板，只在姿态任务显示。狗和自定义项目不默认选择人体模型进行预标注，训练仍可使用人体初始权重做迁移训练。 |
| 完整标注训练流程 | 保留五类任务及三种可切换方式；训练页真实生成模型，模型用于批量候选，再人工检查和微调。 |
| 美化与便捷操作 | 保持 Kudu 参考的 Electron 标题栏、工作流导航、Amber 及三种主题；右侧标签说明、审查导航状态和长表单操作区得到调整。 |

## 新手操作路径

1. 保存并关闭旧版窗口，双击根目录 `双击启动.vbs`。
2. 新建项目，选任务、填写类别、选择图片文件夹和项目位置。
3. 人工标注可直接操作；需要模型辅助时切换右上角“标注方式”。
4. 标注后保存草稿；检查无误后点击“确认无误，下一张”。训练只读取已审核数据。
5. 点击“模型训练”，选择初始权重、CPU/GPU 和参数。完成后在模型列表选择“用于预标注”。
6. 生成候选，进入人工审查，按需接纳和微调。候选生成不会自动覆盖正式标注。
7. 需要交互分割、更多模型、额外图形或导出时使用高级入口；“关闭当前面板”取消弹窗，“返回简洁标注”回到主画布。

“任务”决定训练和标注类型，例如检测或分割；“类别”是要识别的对象，例如人或狗；“目标框”“分割轮廓”“可见骨点”等说明当前图形含义。骨点是姿态任务的一部分，不是独立的工作流。

## 接入与数据保护

- 新增 `inline_tools.py` 和 `desktop/inline-tools.js`；保留 Qt 原控件与动作，转发鼠标、滚轮、键盘和中文文本输入。界面隐藏时暂停图像传输，显示时按可用区域调整尺寸。
- 高级画布保存到同一项目的 `annotations`；返回时主画布重新读取，避免显示旧数据。修复了鼠标按下、移动、释放之间的按键状态丢失。
- 新建项目及切换项目之前检查高级工具是否有未保存内容，避免出现看不见的原生保存询问。
- 正式主画布保存保留哈希冲突检查与备份；候选独立存储，接纳前检查正式标注是否变化。
- 关闭主程序时，主画布修改写入 `.runtime/recovery` 后尝试正式保存；有冲突则保留恢复文件。未完成轮廓的点序列也保留在恢复材料中，尚无一键恢复界面。
- 高级工具中尚未保存的数据在退出前保留恢复副本。已有训练检查点、结果及原始数据不会因退出被删除。
- 运行中任务退出会询问是否停止；超时清理仅面向本应用启动的后台进程。四种常见退出场景已实测，运行中任务的系统确认窗口尚未纳入自动点击验收。

## 范围和剩余验收

Windows 当前环境可运行；Ubuntu 提供 `setup-linux.sh` 和 `start.sh`，尚未在 Ubuntu 桌面实机验收。Windows 运行环境不能直接当作 Linux 环境复制使用。

源码和原版菜单保留；额外模型仍需要对应权重、依赖和许可条件。交互分割入口及控件接入已测，未逐个下载并推理所有模型。OpenGL/点云、全部高级格式/后端、干净电脑便携发行包、大数据集和多屏缩放仍需专项验证。当前内嵌层主要验证了二维标注与普通 Qt 控件，不保证 offscreen 平台支持原版全部图形后端。

自定义骨点在新建时填写顺序和连线；有标注后的模板迁移仍需新项目。狗24预设是骨点定义，不能替代狗姿态训练权重。
