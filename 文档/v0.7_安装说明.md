# v0.7 安装与升级

应用版本为 0.7.0，GitHub 发布标签为 v0.7。Windows 与 Ubuntu 安装包分开提供，不能混用。

## Windows 10/11 x64

下载 Windows 的全部分卷、`parts.json` 和 `join.ps1`，放在同一目录。运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\join.ps1 Windows
```

校验并合并后，运行 `AnnotationWorkbench-0.7.0-Windows-x64-CPU-GPU.exe`，选择新的安装目录，可创建桌面快捷方式。安装包包含 Python、Electron 与 CPU/CUDA 训练依赖，不需要另装 Python；GPU 仍需兼容的 NVIDIA 显卡驱动。程序为未签名开发版。

升级前先保存并退出旧版。建议安装到新目录，通过“打开项目”继续使用原项目，不删除旧程序旁的“工作台数据”。

## Ubuntu 22.04+ x86_64

下载 Ubuntu 的全部分卷、`parts.json` 和 `join.sh`，放在同一目录，运行：

```bash
bash join.sh Ubuntu
sudo apt install ./AnnotationWorkbench-0.7.0-Ubuntu-amd64.deb
```

合并过程会检查 SHA256。安装后从应用菜单打开“标注训练工作台”。应用运行库自带 Python、Electron 和训练依赖；系统图形库由 apt 按包声明补齐。用户数据位于 `~/.config/AnnotationTrainingWorkbench`，项目仍保存在你选择的位置。

## 数据磁盘占用

新版训练不再把整批图片复制进每份数据集快照：唯一图片内容保存在项目 `datasets/.objects`，各快照用硬链接引用。旧项目里已有的重复副本可用项目自带 Python 预演并合并：

```powershell
python scripts\compact_snapshots.py "项目目录"
python scripts\compact_snapshots.py "项目目录" --apply
```

默认只预演、不改文件；`--apply` 才把重复副本合并成硬链接。文件内容不会改变，已冻结快照仍可训练和导出。文件系统不支持硬链接时会自动回退为复制。

## WiFi 摄像头采集

侧栏“WiFi 摄像头采集”连接局域网内的 MaixCAM / MaixCAM2。先在板端运行随附脚本 `desktop/maixcam/maixcam_server.py`（页面上“板端脚本”按钮可直接定位文件），确认终端显示 `Network camera ready`，再在电脑上填写设备 IP 连接。采集的照片经暂存目录进入当前项目 `images`，断线或入库失败时会保留照片，可点“重试入库”。接口是无鉴权的局域网 HTTP，不要把 8080 端口映射到公网。

## 从模型设计开始

1. 新建或打开目标检测项目，点击“模型结构设计”，选择模型并加载结构。
2. 结构页默认是 3D 张量视图；双击模块或按回车可展开内部层级，右侧显示实测输入与输出。
3. 点击模块后选择要修改的组件。YOLOv8n/s、YOLO11n 的顶层卷积可单独设置 padding / stride；其他组件仍限核大小与单层激活。
4. 应用修改后点击“检查并保存修订”。几何修改会重新校准检测步长，通过后才能用于工作台内的从零训练。

检查通过只代表当前输入尺寸的程序链路可运行，不代表识别精度提高。效果需要使用真实数据训练和验证。当前未开放自由增删重连、自动适配和预训练权重迁移。

## 导出到 MaixCAM

“模型转换与量化”页选择“MaixCAM / Pro”模式，只接受标准 YOLO26 检测权重，导出 ONNX FP32（默认 320×224，保留 one2one 分支），并检查 MaixHub 要求的六个节点名称和形状。导出目录附 `labels.txt` 和 `MaixCAM使用说明.md`。INT8 量化在 MaixHub 云端完成，仍需真实校准图片和板端验证。

## 下载与故障排查

只下载需要的平台分卷。完整安装包及分卷会同时占用空间，请预留足够空间。保留校验清单，不把源码 ZIP 当作安装包。

如无法启动，请保留错误提示与启动日志。Windows 日志在程序旁“工作台数据”；Ubuntu 在 `~/.config/AnnotationTrainingWorkbench`。不要删除项目中的图片、标注或训练结果来尝试修复程序。
