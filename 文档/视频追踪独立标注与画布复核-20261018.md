# 视频追踪独立标注与画布复核

日期：2026-10-18

视频追踪页拥有自己的视频播放、帧定位、首帧标注、追踪设置、暂停/续跑与帧列表。标注画布里不显示这些播放和追踪控件，也不再跟着进度轮询切换导航。

## 推荐流程

1. 在“视频追踪标注”导入视频，在共享的绘图工具上标注并保存首帧。
2. 选择逐帧播放或直接追踪。播放时可以拖动进度条；识别到丢失或场景变化时停在问题帧，在本页修正后续跑。
3. 点击“送到画布微调”。已标注帧出现在“视频待微调”来源中；可用 A/D 或侧边缩略图逐张检查、拖动修改并保存。
4. 在标注画布确认当前帧后，系统才会将已复核副本加入数据集。候选草稿和正式数据集相互独立；尚未确认的结果不参与训练。

视频页与标注画布复用同一组绘图工具，但各页分别拥有自己的页面位置和视频控件。离开正在运行的视频时会先请求暂停，轮询只更新进度，不负责切换页面。Windows 的 JSON 原子保存和读取会对短暂文件占用做有界重试；持续拒绝访问仍会显示错误，原文件保留。

MaixHub 的公开站点在本次执行环境中无法连接，故本实现依据用户指定的操作流程与当前本地工程完成；没有宣称复刻或验证 MaixHub 的界面细节。
