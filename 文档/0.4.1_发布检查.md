## 已修复

- 检测项目中的多边形原先可能被静默漏导出，旋转框原先导出为 OBB 标签但仍使用检测任务。现在检测任务全部转为轴对齐矩形，正式 JSON 保留原图形；真正旋转检测使用 OBB 项目。
- 分割项目的圆形转换成 32 点轮廓，避免空标签。
- 移除图片时清理真实 SHA256 划分键；仍有相同内容的图片时保留该组划分。
- 数据划分预览尊重已冻结的分组和设置，新增审核图片进入训练集，与实际生成快照一致。
- 缩略图缓存使用完整路径，避免同名同时间戳的跨项目串图。
- 校验移动后的项目时重新定位数据集 YAML；保留历史快照原文件。
- 外部图片预测支持旋转框和分类统计；流式消费结果，减少批量预测内存占用。视频抽帧支持中文保存路径。
- 哈希计算改用流式读取；图片列表忽略名称像图片的文件夹。
- Windows 高级训练停止使用强制结束自身进程树，并隐藏 taskkill 窗口，避免静默子进程等待软退出。
- 版本号从 package.json 读取，安装器模板统一替换；Linux 源码复制与输入解耦；正式发布重新同步完整源码。
- 新增开发启动脚本、根目录 GPL 许可、第三方说明、忽略规则、GitHub 基础检查、对应源码清单及大文件分卷工具。

## 发布与边界

完整版包含 CPU/CUDA 运行库，安装包数 GB；Windows 为解压式便携程序，Ubuntu DEB 为系统安装包。GPU 仍需兼容 NVIDIA 驱动。程序未签名，未覆盖全部上游模型、导出后端和硬件组合。

Linux 验收环境为现有 WSL Ubuntu/WSLg，自动图形检查使用 `--no-sandbox --disable-gpu`；正式 DEB 菜单入口没有这些开关。尚未在 Ubuntu 22.04 标准桌面真机验证安装和默认沙箱启动，不能视为已完成该平台实机验收。
