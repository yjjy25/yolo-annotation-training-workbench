# 姿态标注规范

适用于工作台的人体 17 点、狗 24 点以及自定义骨点项目。照片与骨点参考入口在标注画布右侧的 **点位示例**。

## 一张照片的标注顺序

1. 选择对象类别，为每个对象画一个贴合目标可见范围的框。
2. 用“模板放置”生成待校准骨点，或选择“顺序点选”逐个定位。
3. 鼠标放到已有骨点上，出现抓取光标后拖动微调；顺序点选中也可以拖动已放置的点，不会增加一个新点。
4. 对照照片检查左右、实例归属与点的可见性。不能判断位置的点按 K 跳过或移除。
5. 检查完成后审核。需要复核的草稿请关闭“保存即审核”，再保存。顺序点选尚未完成时，保存只存草稿，即使开着“保存即审核”也不会提前审核。

同一对象的框和骨点必须属于同一个实例。一张照片中不同对象使用不同实例编号。骨点编号由模板决定，导出顺序不能随着对象朝向改变。

## 可见性规则

| 状态 | 标注判断 | 工作台操作 | YOLO-Pose 导出 |
| --- | --- | --- | --- |
| 可见 | 可以直接看清真实位置 | 正常放点，取消遮挡 | `x y 2` |
| 遮挡 | 被物体、其他肢体或毛发遮挡，但可可靠判断位置 | 放在可信位置，选中后按 O 或勾选遮挡 | `x y 1` |
| 未知 | 画面外，或无法可靠判断位置 | 顺序点选按 K 跳过；已有点选中后按 K 移除 | `0 0 0` |

遮挡点在画布上显示为空心带交叉标记。未知点不在照片上放置，不要把未知点移到左上角，也不要把模板初始位置当作真实位置。

顺序点选时，没有选中已有点，遮挡复选框作用于**下一个新点**，放置后自动重置；拖动或选中已有点时，O 与 K 作用于该选中点。点击照片中的空白位置继续放置下一个点。跳过、移除、遮挡修改、拖动、镜像均可用 Ctrl+Z 撤销，Ctrl+Shift+Z 重做。

## 左右、镜像与反转

- 左右一律按**对象自身**判断。正面朝向观察者时，对象左侧通常出现在照片右侧。
- “新模板左右镜像 / 上下反转”改变下一次放置的模板初始方向，之后仍需逐点校准。
- 选中当前骨架中的点或目标框后，H 左右镜像，Shift+H 上下反转。操作只改变该实例的骨点位置，骨点名称、顺序、遮挡属性及对象框保持对应。
- 几何镜像不自动判断真实的左右解剖关系，也不等于图片增强；镜像后必须对照照片检查。

## 人体 17 点的统一位置

| 编号 | 点位 | 定位约定 |
| --- | --- | --- |
| 1 | 鼻尖 | 鼻尖中央 |
| 2、3 | 左眼、右眼 | 可见眼球区域中心，闭眼时使用眼裂中心 |
| 4、5 | 左耳、右耳 | 耳部中心附近，不以头发轮廓替代 |
| 6、7 | 左肩、右肩 | 肩关节中心，不取衣袖边缘 |
| 8、9 | 左肘、右肘 | 肘关节中心 |
| 10、11 | 左腕、右腕 | 前臂与手掌连接处的腕关节中心 |
| 12、13 | 左髋、右髋 | 髋关节中心附近，不能用裤袋位置代替 |
| 14、15 | 左膝、右膝 | 膝关节中心 |
| 16、17 | 左踝、右踝 | 小腿与足部连接处的踝关节中心 |

## 狗 24 点的顺序与约定

| 编号 | 点位 |
| --- | --- |
| 1～3 | 左前爪、左前膝、左前肘 |
| 4～6 | 左后爪、左后膝、左后肘 |
| 7～9 | 右前爪、右前膝、右前肘 |
| 10～12 | 右后爪、右后膝、右后肘 |
| 13、14 | 尾根、尾尖 |
| 15、16 | 左耳根、右耳根 |
| 17、18 | 鼻尖、下巴 |
| 19、20 | 左耳尖、右耳尖 |
| 21、22 | 左眼、右眼 |
| 23、24 | 肩隆、喉部 |

狗模板保留已安装 Ultralytics dog-pose 的点名与顺序，部分肢体名称沿用上游，不能仅凭“膝/肘”文字判断动物解剖位置。请先由标注负责人确定各肢体关节位置，审核一张清晰的侧面照片作为项目示例，再推广到整批数据。

爪取爪部/接地端中心；尾根取尾与躯干连接处；尾尖取尾巴末端；耳根取头耳连接处中心，耳尖取耳廓最远端；肩隆取颈后肩背交界处；喉部取头颈连接处腹侧中心。

## 自定义模板与照片参考

先为每个自定义骨点约定固定的物理位置，记录左右配对、连线和编号；使用同一规则标完整批数据。在工作台标好一张清晰照片后，打开规范面板，点 **将当前照片设为示例**，保存照片与骨点快照。此参考位于项目 `references/`，重新打开项目仍可查看，原标注继续编辑不会悄悄改变参考快照。

内置人体照片及标注来自项目已有的 X-AnyLabeling `examples/estimation/pose_estimation/sources/human-pose.jpeg` 与同名 JSON。内置狗照片已换为 Ultralytics 官方 Dog-Pose 数据包中的两张全身照片，按照片坐标叠加编号及连线。点击编号会在照片的相应位置显示粉色圆圈与名称引线，也可点击照片上的点反向选择编号。前 20 点沿用数据集原始坐标；官方包中 21～24 没有有效原始坐标，此处以橙色显示人工教学定位，仅表示眼睛、肩隆、喉部的近似解剖位置，不作为原始数据真值。来源及完整坐标记录在 `anylabeling/resources/pose_examples/dog24-examples.json`。自定义模板需设置自己的照片示例。所有示例与示意图仅用于对照，不自动加入训练数据。

## 视频逐帧标注

新建项目时将“导入来源”选为视频，或在已有项目的数据页点“导入视频标注”。设置起止时间、抽帧间隔和本次上限；间隔 0 表示逐帧，默认间隔 1 秒、最多 500 帧，单次最多 5000 帧。导入在后台进行，可以取消；解码失败会显示错误。

导入后通过画布时间条、上一帧/下一帧或 A/D 切换采样帧，每帧独立保存和审核。原始帧号从 0 开始，秒数按视频解码帧率估算，变帧率视频的精确播放时间可能不同。原视频保持原样；项目 `videos/` 中记录源路径、大小、修改时间、帧率及每帧对应关系。

这是视频抽帧后的逐帧标注，不会自动跟踪或把上一帧骨点复制成下一帧真值。跨帧实例编号需人工保持一致。相邻视频帧相似，训练与验证尽量使用不同视频，避免仅凭相邻帧取得虚高指标。

## 审核清单

- 框与骨点属于正确对象，同图多对象未混用实例。
- 所有左右点按对象自身判断，镜像后再次检查。
- 骨点落在统一的解剖位置，模板占位已人工校准。
- 可见、遮挡、未知区分正确，无法可靠定位的点不猜测。
- 视频帧逐张核对，清晰度不足的样本不勉强标注。
- 人工复核通过后再纳入训练。


## 其他任务的遮挡标记与训练作用

检测、分割、旋转框可在右侧“遮挡标记”中勾选选中对象被遮挡，也可按 O 切换，支持框选后批量设置。分类任务记录整张照片中分类主体的遮挡情况。此属性独立于类别与困难样本属性，保存后重新打开仍会保留。

普通 YOLO 检测、分割、旋转框与分类没有独立遮挡训练字段，因此只勾选这个选项不会直接改变训练标签或损失。它可帮助人工复核、记录遮挡样本，不会自动过滤、加权或改变采样比例。提高遮挡场景效果主要靠增加真实且有代表性的遮挡样本、统一标注尺度，并在独立测试集上比较。

检测框/旋转框请事先统一项目规则，不要一部分按可见范围、一部分猜完整范围。无法可靠判断完整范围时，按约定的可见范围标注。实例分割只沿可见区域标注，不猜遮挡物后面的轮廓；互不相连的可见区域需要明确数据组织规则。分类只在主体仍可可靠识别时赋类别，过度遮挡或无法识别的照片应复核或移出数据集。

姿态关键点与对象遮挡标记不同：点的 v=0/1/2 会进入 YOLO-Pose 标签。但 1 与 2 不一定具有不同损失权重；常见 Ultralytics 实现将非零可见性的点都用于坐标学习，未知点 v=0 不参与该坐标监督，不能把“勾选遮挡”理解为自动获得额外权重。


照片面板可切换不同全身示例。若项目自定义照片没有某个骨点，选中该点会显示缺失提示，不会用模板坐标猜测照片位置。


## 当前点位、标签快捷键和设置记忆

右侧“下一骨点”以大字显示当前名称和编号，例如“左前肘，3 / 24”。点“查看这个点的位置”会直接打开照片并高亮该点，不用再从24个名称中重新选择。拖动已有骨点时显示“正在微调”，并提示接下来要标的点。

| 快捷键 | 操作 |
| --- | --- |
| Tab | 切换下一个标签，例如猫→狗→猫 |
| Shift+Tab | 切换上一个标签 |
| 1～9 | 选择对应编号的标签 |
| V / R | 选择模式 / 画图模式 |
| O / K | 遮挡 / 跳过未知点 |
| H / Shift+H | 当前骨架左右镜像 / 上下反转 |

Tab、数字键和标签按钮不会中断正在点选的骨架或未完成轮廓。检测、分割、旋转框与姿态的标签切换用于后续标注；修改已有对象的类别时，请选中对象并点击“应用到选中对象”。整图分类切换标签会直接更新当前照片类别。在文本输入框和弹窗中保留正常的Tab焦点导航。

放置方式、模板镜像方向、当前标签、图形工具和手动选择的画图/选择模式按项目保存在本机界面设置中。切换图片和重新打开界面会恢复这些设置。模板放置完成后临时进入微调，不会把下一张也锁定为选择模式。遮挡状态属于各点，不会跨点自动沿用，以免误标。

镜像和模板方向可在“模板与镜像”中展开设置；类别说明、操作说明、AI候选等默认折叠，常用的当前点、遮挡和跳过保持展开。
