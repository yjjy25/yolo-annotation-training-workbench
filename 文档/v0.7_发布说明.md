# v0.7 发布说明

日期：2026-11-07。应用版本：0.7.0。GitHub 标签：v0.7。

## 本版内容

- **WiFi 摄像头采集**：工作台通过局域网连接 MaixCAM / MaixCAM2 板端脚本，实时预览、单张拍照与按间隔连续采集；照片经暂存目录分批进入当前项目 `images`，断线、画面过期或入库失败时停止采集并保留照片，可重试入库。板端脚本为 `desktop/maixcam/maixcam_server.py`。
- **MaixCAM / Pro 导出**：标准 YOLO26 Detect 权重导出 ONNX FP32（默认 320×224），显式保留 one2one 分支，检查 MaixHub 要求的六个检测节点名称与形状，并做 ONNX 与 CPU 推理检查；导出目录附类别表与云端量化说明。不匹配的模型会被明确拒绝。
- **训练初始权重**：训练页显示内置模型是否已缓存，可允许从 GitHub 下载缺失权重并查看进度；新增“从零训练”入口。显式选择的本地权重严格按路径使用，缺失时不再静默退回同名模型。
- **数据集快照去重**：快照内图片改为硬链接到 `datasets/.objects/<sha256>`，不再为每次训练复制整批 JPEG；文件系统不支持硬链接时回退为复制。manifest、`data.yaml`、ZIP 导出与旧快照行为不变。新增 `scripts/compact_snapshots.py`，默认只预演，`--apply` 合并历史重复副本。
- **划分策略可选**：默认按图片划分，至少两张已确认图片即可开始训练；可勾选“按来源与相似图片整组划分”，此时同源视频和已识别重复图片不跨集合。
- **视频抽帧无损**：新导入的视频帧按原分辨率保存为 PNG，避免二次 JPEG 压缩；旧 JPG 会话按记录的帧名继续工作。
- **模型结构 3D 视图**：结构页默认显示可旋转、缩放的 3D 张量，支持逐级展开重复块、卷积组与独立算子，并显示实测输入输出。
- **几何编辑**：YOLOv8n/s、YOLO11n 的顶层卷积可单独设置 padding / stride；显示预计与实际输出尺寸、首个下游冲突位置，并重新校准检测步长后保存修订。

提供 Windows x64 EXE 与 Ubuntu amd64 DEB，包含各平台独立运行库。安装方法见 [v0.7 安装说明](v0.7_安装说明.md)。

## 验证记录

- `npm --prefix desktop run check` 通过（含新增的采集、几何、3D 视图脚本语法检查）。
- `npm --prefix desktop test` 通过，覆盖模型几何、3D 层级、MaixCAM 采集流程，以及原有标注、姿态、项目、视频、划分和训练进度回归。
- Python 回归：`tests/workflow` 与 `tests/test_auto_training` 共 350 项通过、1 项跳过（2026-11-07），覆盖快照硬链接与回滚、划分策略、视频帧格式、模型几何、导出配置与训练权重解析。
- 修正测试收集：`pytest --doctest-modules` 不再导入 `tests/workflow/*_probe.py` 这类手工探针脚本，也不会收集运行时生成的 `model_designs` 目录；含中文路径的 YAML 测试改为显式 UTF-8 读取，不再受 Windows 区域编码影响。
- 安装包的逐文件源码、归档 CRC/路径、版本与 SHA256 检查结果见发布资产中的校验文件。

未完成或未覆盖的范围：MaixCAM 采集仅在本地模拟摄像头与模拟板端接口上回归，真实设备、不同网络与 MaixCAM2 仍需实机验证；MaixCAM 导出未执行 MaixHub 云端编译与板端精度验证；本版安装包未在原生 Windows 上做完整人工验收，也未逐一验证全部模型、尺寸和硬件组合。
