# 标注训练工作台 0.5.1：开始使用

双击 Windows 的 `AnnotationWorkbench.exe`，或从 Ubuntu 应用菜单打开“标注训练工作台”。窗口内出现“本地引擎就绪”后即可使用，无需另开标注程序。

## 第一次标注

1. 点击“新建项目”，选择任务：目标检测、实例分割、姿态、旋转框或图片分类。
2. 输入要识别的类别，多个类别用逗号分隔，例如 `猫, 狗` 或 `站立, 趴卧`。
3. 选择项目位置并创建空项目，再在“数据与标注”点击“导入数据”添加图片或视频。软件保留原始数据。
4. 在“标注画布”右侧选择类别，再标注对象。同一张图可以同时有多个类别、多个对象。
5. 检查无误后点击“保存审核，下一张”，或按 S / Ctrl+S。保存成功即审核并自动下一张；内部切图保存仍为草稿。

类别可通过右侧按钮、下拉框或数字键 1–9 切换。修改已有对象时，先选中对象，再选新类别，点击“修改选中对象的类别”。

## 姿态标注

选姿态任务后才会出现骨点设置。可选人17、狗24或自定义骨点。

先为对象画框，再放置骨点模板并逐点拖动校准；也可切换为按顺序点选。遮挡点可标为遮挡，不可见的点可跳过。每个对象的框、类别和骨点独立分组。例如一只狗标“站立”，另一只狗标“趴卧”。同一项目使用相同的骨点定义及顺序。

狗24是骨点模板，未附带现成的狗姿态识别模型。狗和自定义骨架可以用人体姿态模型初始化训练；自动标注须选择骨点匹配的模型。

## 选择标注方式

右上角可在三种方式间切换，已有标签会保留。

| 方式 | 怎么用 |
| --- | --- |
| 人工标注 | 直接画框、轮廓或骨点，无需模型 |
| 预训练模型预标注 | 选模型与类别映射，为全部图片生成候选，再人工检查 |
| 少量标注后训练 | 先人工标注并确认一部分图片，训练专用模型，再批量生成候选并审查 |

自动生成的候选独立保存，不会直接改写人工标签。接纳候选后仍需检查、微调并确认。

## 训练模型

打开“模型训练”，选择模型、CPU 或 NVIDIA GPU，填写轮数、批大小、图片尺寸、学习率等参数，点击“开始训练”。完成后，在模型列表点“用于预标注”。

至少需要两张内容不同的已确认图片，才能划分训练与验证；实际训练请准备足够多样的数据。结果保存在项目 `runs`，推荐使用 `weights/best.pt`。随包提供 YOLOv8n 检测、分割、姿态以及 YOLO11n 检测权重；其他模型首次使用可能需要联网。GPU 需要兼容的 NVIDIA 驱动，显存不足时减小批大小或图片尺寸。

简洁页使用 SGD 优化器，初始学习率按填写值生效；其他优化器可在高级训练页设置。AMP 默认关闭，开启后可能首次联网下载框架检查用的模型。

## 更多功能与退出

“高级标注”“交互分割 / 更多模型”“高级参数与模型导出”在当前窗口显示原版工具。高级面板保存后点击“返回简洁标注”。额外模型仍需对应权重和依赖；所有高级后端尚未逐项验证。

点击右上角“×”退出；有训练等任务运行时会询问是否停止。退出会尝试保存并保留恢复副本；发生冲突时恢复文件需人工处理，目前没有一键恢复界面。

## 数据与源码位置

- Windows：程序旁的“工作台数据”。移动程序前先退出，并一起移动该目录。
- Ubuntu：`~/.config/AnnotationTrainingWorkbench`；通过 apt 更新程序不会清除这里的项目。
- 项目内：`images` 图片副本、`annotations` 正式标注、`proposals` 候选、`datasets` 训练快照、`runs` 结果、`backups` 备份。
- 界面源码：`resources/app`；扩展源码：`resources/workbench/X-AnyLabeling`；许可随源码和运行库保留。

启动失败时点“查看日志”，训练失败时查看训练页日志中的实际错误。本包为未签名开发版。

## 0.4.1 数据转换与移动项目

检测项目允许绘制普通框、旋转框、多边形和圆形，训练时统一转换为轴对齐框；需要保留旋转方向进行训练时创建“旋转框”项目。分割项目的圆形会转换为 32 点轮廓。正式 JSON 保留原图形。

验证时会重新定位当前项目中的数据快照，因此可以在退出程序后整体移动项目；历史日志里的原路径仅作记录。删除图片默认移入项目 removed 目录，并清理对应的内容哈希划分；已有数据集快照和训练结果保留。

## 0.5.0 视频与训练

视频追踪在独立页面标注，自动结果送到“视频待微调”总览检查。微调保存后才加入数据集。追踪丢失或变化过大时暂停，修正后可继续；进度条可定位帧。

模型训练页显示本次使用的训练集、验证集数量、实时进度与预计完成时间，首轮结束后按实际速度估算，早停可能提前完成。独立测试集目前未自动划分。

模型验证选择视频后逐帧预测，完成后在验证页播放带标记视频，可暂停、拖动进度与全屏查看。结果不含原音轨。


## 0.5.1 模型转换与量化

打开项目后进入“模型转换与量化”，选择本地或已训练的 PT 权重。页面显示原权重实际存储精度及转换目标；点击格式、精度旁的“!”查看说明。

第一次推荐 ONNX + FP32。ONNX 还支持 FP16（需要目标推理软件和设备支持）和 INT8（需要真实校准图片）；TorchScript 当前提供 FP32。

INT8：准备约 100 张有代表性的真实训练图片到单独文件夹，无需标注，不使用最终测试集。选择该目录后点击“开始转换”，软件会自动读取与预处理图片进行校准。点击校准文件夹旁“!”查看完整四步说明。

每次输出保存在项目 exports 的独立目录，原始权重保留。支持查看日志和停止转换，参数和 SHA256 写入 export.json。转换成功不代表识别精度或速度已经验证，需在目标推理软件中用独立验证集检查；当前模型验证页面仍只接收 PT。
