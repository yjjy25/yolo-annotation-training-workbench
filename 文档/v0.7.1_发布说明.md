# v0.7.1 发布说明

日期：2026-11-07。应用版本：0.7.1。GitHub 标签：v0.7.1。

## 本版内容

- **训练完直接转换**：训练状态区新增“转换这个模型”／“转换最新模型”，“已训练模型”每行和“项目模型管理”每行新增“转换”，都会带着对应 `best.pt` 进入“模型转换与量化”。转换页下拉框改用“训练 11-07 03:15 · 本项目模型”这样的可读名称，最新训练排在最前并默认选中，选中后显示权重路径尾部；删除项目模型时会同步从下拉框移除。
- **不建项目也能转换**：未打开项目时可在转换页点“选择本地 PT 权重”，选任意自己的 `.pt` 直接转换。打开项目时结果写入项目 `exports`；未打开项目时写入工作台数据的 `exports`，`export.json` 记录本次范围（`scope`）与来源目录。原权重不会被修改。
- **MaixCAM 导出扩展到四个家族**：YOLOv5u、YOLOv8、YOLO11、YOLO26 的目标检测权重都可导出到 MaixHub。导出时按网络实际结构识别家族（不看文件名），检查输入尺寸与输出结构并做一次 CPU 推理；导出目录的说明会写明 MaixHub 上应选择的模型类型。分割、姿态、旋转框、分类，以及 one2one 分支被融合的 YOLO26 会明确拒绝。
- **更可读的失败提示**：无法按 Ultralytics 加载的 PT（例如旧版 `ultralytics/yolov5` 权重）现在直接说明原因和处理办法，不再抛框架内部报错；`export.json` 中的失败记录也保留这条原因。

本版是 0.7 的修正与体验更新，不改变已有项目的图片、标注、快照与训练结果。安装包沿用已发布并校验的 0.7.0 运行库，只替换应用源码、说明与版本信息。

## 验证记录

- `npm --prefix desktop run check` 通过（含新增的 `export-scope.js` 与其测试）。
- `npm --prefix desktop test` 通过，包含新增的转换范围、训练记录查找与可读名称用例，以及原有标注、姿态、视频、划分、几何、3D 与采集回归。
- Python 回归 275 项通过、1 项跳过（2026-11-07，`tests/workflow`），覆盖 MaixCAM 家族识别、拒绝路径、ONNX 输出结构检查与转换记录。
- 安装包的逐文件源码、归档校验、版本与 SHA256 记录随发布资产提供。

未覆盖范围：MaixCAM 的四个家族只做本地 ONNX 结构检查与 CPU 推理，未在 MaixHub 云端逐一编译，也未做板端精度验证；本版未在原生 Windows 上做完整人工验收；真实 MaixCAM 设备与不同网络环境仍未实机验证。发布包为未签名开发版。

## 下次更新方向

1. **工程化模型转换**：把更多模型家族的云端转换要求固化为可检查的配置，减少手工核对。
2. **模块与连线编辑**：在固定连接之外逐步开放模块增删与重连，并核对通道、空间尺寸与检测步长。
3. **实验对比**：在同一划分上比较原始结构与修改结构的训练结果。

以上是后续方向，尚未在本版实现。
