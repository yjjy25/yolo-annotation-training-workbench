# 模型转换与量化

本次功能已加入工作区源码，尚未重新生成安装包。重新运行根目录的“双击启动.vbs”后，进入侧栏“模型转换与量化”。也可以在“模型训练”的已训练模型列表点击“转换 / 量化”。

1. 打开或新建一个项目，选择本项目训练权重或本地 YOLO `.pt` 文件。
2. 选择 ONNX 或 TorchScript，再选择精度与图片尺寸。TorchScript 当前只提供 FP32；尺寸必须为 32 的倍数。
3. ONNX INT8 需要校准图片文件夹，支持子文件夹，无需标注。默认最多使用按路径排序的前 100 张图片。建议准备至少 100 张覆盖真实部署场景的训练图片，避免使用最终测试集。少量图片仅适合测试流程。
4. 点击“开始转换”，查看运行状态与日志。可以停止，运行中不能切换项目或启动训练、预标注、验证。
5. 点击“打开输出目录”。每次输出位于项目 `exports/<时间戳-唯一标识>/`，包括模型、`export.json` 和 `export.log`。原始权重不会覆盖。失败或停止目录可能留有未完成文件，应依据记录状态判断，不能直接部署。

| 目标 | 精度 | 转换与检查 |
| --- | --- | --- |
| ONNX | FP32 | CPU 导出、ONNX 结构检查、一次 CPU 推理 |
| ONNX | FP16 | FP32 导出后转换内部算子，保留 FP32 输入输出、重新排序节点、结构检查 |
| ONNX | INT8 | 代表性图片静态 QDQ 校准，Conv / MatMul / Gemm 量化，逐通道权重，结构检查与一次 CPU 推理 |
| TorchScript | FP32 | 保留 Ultralytics 元数据、重新加载并进行一次 CPU 推理 |

固定输入为 `1 × 3 × imgsz × imgsz`。检测、分割、姿态和旋转框采用 RGB、按比例缩放补边、除以 255；分类使用 Ultralytics 分类预处理。实际输出结构与后处理取决于模型任务及版本。当前不包含 TensorRT / OpenVINO 导出，也没有把部署格式接入现有 PT 模型验证页面。

FP16 需要目标推理引擎支持半精度算子。INT8 不保证加速或保持任务精度；必须在目标设备和真实验证集重新测量。缺失 ONNX 依赖会明确报错，工作台不会自动安装依赖。
