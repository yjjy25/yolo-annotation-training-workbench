# 空项目创建、后续导入与视频追踪播放

本次修改已应用到本地源码，已发布 0.4.1 安装包尚未重新构建。

## 创建项目与导入数据

新建项目只需设置任务、类别、保存目录；姿态任务另外选择骨点模板。创建后进入数据集，不要求选择图片或视频。

数据集页上方和空项目提示区提供“导入数据”按钮，可以多次追加：

- 图片文件夹：递归导入支持的图片。
- 图片文件：系统文件选择框支持多选。
- 视频追踪标注：带入所选视频，进入独立追踪流程。
- 视频抽帧后手动标注：进入原有抽帧导入流程。

图片复制到当前项目，保留原文件。相同名称且内容相同的已有图片跳过；名称或标注文件名冲突时自动改名，不覆盖原图片或标注。图片旁的同名 JSON 标注在通过当前任务/类别校验后导入，并设为待审核；不匹配或损坏的内容会明确报错。本批次导入前先检查、暂存，发布失败时回退本次新增文件。

## 视频追踪运行方式

手动标注起始帧后，在画布上方“运行方式”选择：

| 方式 | 行为 |
| --- | --- |
| 直接追踪到暂停（较快） | 后台连续追踪，不逐帧播放；遇到需要修正的帧、检查点或片段结束时显示结果。 |
| 逐帧播放预览（不跳帧） | 每个原始帧连同追踪标注显示后，再继续处理下一帧；处理较慢时播放也会放慢。 |

播放帧数与保存数量分开：即使逐帧播放，仍按导入时设置的保存间隔写入训练图片，不会仅因播放而保存所有帧。预览中不能编辑；点“暂停追踪”后，会保存当前有效帧并恢复编辑。追踪失败的问题帧仍不自动写入猜测标签，需要手工标注后继续。

预览不会改写起始人工标注。自动结果保持待审核，人工确认后才进入训练集。既有丢失、外观变化、出画、位移/尺度变化和定期检查点规则继续生效。预览连接长时间没有响应也会暂停并保留当前结果。
