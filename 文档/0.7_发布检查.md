# 0.7 发布检查

日期：2026-11-07。应用版本 0.7.0，标签 v0.7。

## 源码与回归

| 项目 | 结果 |
| --- | --- |
| `npm --prefix desktop run check` | 通过（含采集、几何、3D 视图脚本） |

修复记录：

- pytest 收集阶段不再导入 `tests/workflow/*_probe.py`（手工兼容性探针，导入即跑整模型前向并写工作目录），并排除运行时生成的 `model_designs` 目录；`tests/workflow/conftest.py` 声明 `collect_ignore` / `collect_ignore_glob`。
- `test_checked_snapshot_rejects_tampering_and_wrong_training_input` 读取含中文路径的 YAML 改为显式 UTF-8，避免 Windows 区域编码（GBK）报错。
- 打包脚本原先只复制 `desktop/` 顶层文件，新增的 `desktop/maixcam/maixcam_server.py` 不会进入安装包，界面的“板端脚本”按钮会指向不存在的路径。已把 `build_release.py`、`rebuild_from_release.py` 与 `verify_release.py` 的源码收集改为递归并包含 `.py`，`verify_release.py` 会逐个核对新文件。

## 安装包构建

基于已发布并校验 SHA256 的 v0.5.2 运行库重建，只替换应用源码、字体说明与版本信息：

- Windows：`.packaging/rebuild_from_release.py windows`，安装器解压桩的等长版本字符串更新 2 处，产物 `AnnotationWorkbench-0.7.0-Windows-x64-CPU-GPU.exe`。
- Ubuntu：WSL 内 `dpkg-deb -x` 解出基础包后刷新应用源码，WSL 生成文件/符号链接清单，Windows 端用 zstd 重新打包 DEB。
- 逐文件源码核对：`verify_release.py` 校验 EXE 的 ZIP CRC、DEB 的流式归档、全部应用源码哈希与版本，输出 SHA256 清单。

构建结果与 SHA256 见 `发行包/校验/release-0.7.0.json`。
