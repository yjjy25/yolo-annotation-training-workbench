# 检测头分步选择与布局优化

原来的内部组件选择把完整源码路径平铺进原生下拉框，条目高度相似，展开后遮住结构图。

现在按“预测内容 → 特征输入 → 内部处理层 → 可修改内容”逐步选择。“框在哪里”和“是什么目标”分别映射真实的位置与类别预测分支；输入尺寸来自实际前向检测，不根据层号猜测。

可修改项解释卷积核和激活函数的作用、修改范围和效果限制。只读组件、完整路径、输入输出、源码与来源信息默认收进技术详情。双分支检测头的一对一/常规分支放在高级折叠项中。其他模块也按实际父组件分组选择。

后端结构构建、参数编辑范围及训练验证规则保持原有逻辑。自动应用行为保留。
