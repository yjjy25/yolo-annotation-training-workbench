# v0.7.2 发布说明

日期：2026-11-08。应用版本：0.7.2。GitHub 标签：v0.7.2。

## 本版内容

- **快捷键介绍**：侧栏底部新增“快捷键介绍”按钮，任何时候按 `F1` 也能打开。窗口按“常用标注 / 类别与切图 / 画布与姿态 / 工作区”四类列出按键与作用，常用操作（画框、选择、保存审核、撤销重做、删除、Esc、接纳 AI 候选）与切图、姿态、工作区切换都在同一处查阅。
- **不打断标注**：弹窗打开时标注快捷键暂停，`Esc` 关闭并把焦点还给打开前的控件；输入法输入过程中不会误触发，`F1` 也不会被浏览器或系统占用。
- **跟随主题**：弹窗与侧栏按钮使用同一套浅色 / 深色变量，窄窗口下自动收窄留白。

本版是 0.7.1 的界面补充，不改变项目数据、训练结果与转换逻辑。安装包沿用已发布并校验的 0.7.1 运行库，只替换应用源码、说明与版本信息。

## 验证记录

- `npm --prefix desktop run check` 通过（含全部界面与工具脚本的语法检查）。
- `npm --prefix desktop test` 通过，包含标注键盘、姿态、画布异步、划分、训练进度、几何、3D、采集与转换范围的既有回归。
- 安装包的逐文件源码、归档校验、版本与 SHA256 记录随发布资产提供。

未覆盖范围：快捷键弹窗未做 Electron 自动化点击验收，仅通过脚本测试与静态检查核对事件绑定与页面结构；本版未在原生 Windows 上做完整人工验收。

## 下次更新方向

1. **更多端到端验收**：为新增弹窗补充可自动化的点击与键盘验收。
2. **模块与连线编辑**：在固定连接之外逐步开放模块增删与重连。
3. **实验对比**：在同一划分上比较原始结构与修改结构的训练结果。

以上是后续方向，尚未在本版实现。
