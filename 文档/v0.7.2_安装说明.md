# v0.7.2 安装与升级

应用版本为 0.7.2，GitHub 发布标签为 v0.7.2。Windows 与 Ubuntu 安装包分开提供，不能混用。

## Windows 10/11 x64

下载 Windows 的全部分卷、`parts.json` 和 `join.ps1`，放在同一目录。运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\join.ps1 Windows
```

校验并合并后，运行 `AnnotationWorkbench-0.7.2-Windows-x64-CPU-GPU.exe`，选择新的安装目录，可创建桌面快捷方式。安装包包含 Python、Electron 与 CPU/CUDA 训练依赖，不需要另装 Python；GPU 仍需兼容的 NVIDIA 显卡驱动。程序为未签名开发版。

升级前先保存并退出旧版。建议安装到新目录，通过“打开项目”继续使用原项目，不删除旧程序旁的“工作台数据”。

## Ubuntu 22.04+ x86_64

下载 Ubuntu 的全部分卷、`parts.json` 和 `join.sh`，放在同一目录，运行：

```bash
bash join.sh Ubuntu
sudo apt install ./AnnotationWorkbench-0.7.2-Ubuntu-amd64.deb
```

合并过程会检查 SHA256。安装后从应用菜单打开“标注训练工作台”。应用运行库自带 Python、Electron 和训练依赖；系统图形库由 apt 按包声明补齐。用户数据位于 `~/.config/AnnotationTrainingWorkbench`，项目仍保存在你选择的位置。

## 模型转换：从训练结果直接开始

1. 训练完成后，训练状态区出现“转换这个模型”，点击即跳到“模型转换与量化”，并已选中本次的 `best.pt`。
2. “已训练模型”列表每行的“转换 / 量化”同样直达转换页；“项目模型管理”每行的“转换”可用于放进项目 `models` 的 PT 权重。
3. 也可以不打开项目：在转换页点“选择本地 PT 权重”，选任意自己的 `.pt` 直接转换。打开项目时结果写入项目 `exports`；没有打开项目时写入工作台数据的 `exports`，`export.json` 会记录本次范围与来源目录。原权重不会被修改。
4. 下拉框用“训练 11-07 03:15 · 本项目模型”这样的名称区分同名模型，最新的训练排在最前；选中后下方“当前模型”显示权重路径尾部。

## 导出到 MaixCAM

“模型转换与量化”页选择“MaixCAM / Pro”模式，支持 YOLOv5u、YOLOv8、YOLO11、YOLO26 的目标检测权重，导出 ONNX FP32（默认 320×224，两边为 32 的倍数）。导出时按网络实际结构识别家族，并检查输入尺寸、输出结构与一次 CPU 推理；导出目录附 `labels.txt` 和 `MaixCAM使用说明.md`，其中写明在 MaixHub 上应选择的模型类型。

旧版 `ultralytics/yolov5` 权重、分割/姿态/旋转框/分类模型会被明确拒绝，并提示改用通用模式；加载不了的非 Ultralytics 权重会说明原因，而不是给出框架内部报错。INT8 量化仍在 MaixHub 云端完成，需要真实校准图片和板端验证。

## 快捷键介绍

侧栏底部新增“快捷键介绍”按钮，任何时候按 F1 也能打开。窗口按“常用标注 / 类别与切图 / 画布与姿态 / 工作区”四类列出按键与作用，说明文字直接写在按键旁边；弹窗打开时标注快捷键暂停，Esc 关闭并回到原来的焦点位置。输入法输入中不会触发。

## 数据磁盘占用

训练不再把整批图片复制进每份数据集快照：唯一图片内容保存在项目 `datasets/.objects`，各快照用硬链接引用。旧项目里已有的重复副本可用项目自带 Python 预演并合并：

```powershell
python scripts\compact_snapshots.py "项目目录"
python scripts\compact_snapshots.py "项目目录" --apply
```

默认只预演、不改文件；`--apply` 才把重复副本合并成硬链接。文件内容不会改变，已冻结快照仍可训练和导出。

## WiFi 摄像头采集

侧栏“WiFi 摄像头采集”连接局域网内的 MaixCAM / MaixCAM2。先在板端运行随附脚本 `desktop/maixcam/maixcam_server.py`（页面上“板端脚本”按钮可直接定位文件），确认终端显示 `Network camera ready`，再在电脑上填写设备 IP 连接。采集的照片经暂存目录进入当前项目 `images`，断线或入库失败时会保留照片，可点“重试入库”。接口是无鉴权的局域网 HTTP，不要把 8080 端口映射到公网。

## 下载与故障排查

只下载需要的平台分卷。完整安装包及分卷会同时占用空间，请预留足够空间。保留校验清单，不把源码 ZIP 当作安装包。

如无法启动，请保留错误提示与启动日志。Windows 日志在程序旁“工作台数据”；Ubuntu 在 `~/.config/AnnotationTrainingWorkbench`。不要删除项目中的图片、标注或训练结果来尝试修复程序。
