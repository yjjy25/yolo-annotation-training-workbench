# 0.5.2 发布检查

版本日期：2026-10-21（构建与验收跨 10 月 20～21 日）。构建目标：Windows x64 CPU/CUDA 自带环境 EXE、Ubuntu amd64 DEB，以及对应源码。

修改版本前已创建并验证源码和项目备份：6,312 个文件、538,143,704 字节。回归、实际包内流程和包体校验完成后在本文件记录结果。

许可维持 GPL-3.0-only，并保留上游与第三方组件许可。源码包排除用户项目、备份、维护清理记录、运行环境和模型权重。

验证边界：WSLg 的离线运行验证不能替代 Ubuntu 标准桌面/默认沙箱安装验收。合成流程数据不代表实际识别精度或量化效果。

## 完成的验证

- 28 个 Python 工作流/训练测试模块，共 270 项通过。视频子进程测试的临时进度 JSON 改为与真实工作进程一致的原子发布，避免把半写文件当成完整结果；训练停止模块在正常本机权限下复测通过。
- JavaScript 全部语法检查及画布边缘、姿态/遮挡、快捷键、异步保存、图片缓存、数据划分和训练进度等回归通过。
- Windows 自带环境与 Ubuntu/WSLg 自带环境的回收站、缩略图、大图预览、固定关闭按钮、项目导出/导入和导入后保存，各 22 项界面验收通过。
- Windows NVIDIA RTX 5060 Laptop GPU 与 Ubuntu/WSLg CPU 的检测、狗 24 点姿态任务均实际完成多实例标注、保存审核、一轮训练及候选生成。两张已审核图片被跳过，四张未标注图片各生成一个候选；正式人工标注哈希不变。
- Linux 包内预标注子进程曾加载运行库的旧版 anylabeling；启动器现为所有子进程明确设置随包源码 PYTHONPATH，并重新通过检测、姿态完整流程。
- 真实 Windows EXE 使用 --extract-only 解压成功；从最终解压程序再完成 22 项回收站/迁移验收。
- Windows ZIP64 全部 CRC、Ubuntu DEB 流式读取、Linux chrome-sandbox 所有权/权限、用户数据排除检查通过。两平台各 1519 个应用源码/资源文件与当前源码对应（Linux CSS 额外附字体声明）。
