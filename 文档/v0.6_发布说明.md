# v0.6 发布说明

日期：2026-10-25。应用版本：0.6.0。GitHub 标签：v0.6。

## 本版内容

新增固定连接的检测模型结构设计、参数编辑、真实输入输出检测、修订检查与训练回放。检测头按“框在哪里 / 是什么目标 → 输入特征尺寸 → 处理层 → 可修改内容”分步选择，源码路径和只读组件默认收起。

支持五个模型家族的 25 个规模模板；可编辑符合规则的卷积核、池化核和单层激活函数，支持撤销、恢复默认结构、历史修订和源码身份校验。数据划分增加同源视频及已识别重复/相似图片的分组和快照哈希核对。

提供 Windows x64 EXE 与 Ubuntu amd64 DEB，包含各平台独立运行库。安装方法见 [v0.6 安装说明](v0.6_安装说明.md)。运行库以已发布且核对 SHA256 的 v0.5.2 安装包为基础保留，重新写入本版应用源码、说明与版本信息；不会把旧源码包改名充当新安装包。

## 验证记录

- `npm --prefix desktop run check` 通过。
- `npm --prefix desktop test` 通过，包含检测头分组、真实父子关系、输入尺寸和原有标注/项目/视频等回归。
- 模型设计、数据划分与项目快照 Python 回归 51 项通过（2026-10-25）。pytest 安装在临时测试目录，未修改应用依赖。
- 检测头界面 Electron 验收 59 项通过，覆盖分步选择、限定分支修改、只读信息、历史修订、YOLO26 双分支和窄窗口布局。原始记录见 [界面验收](检测头分步选择_证据_20261023/最终验收/report.json)。
- 安装包的逐文件源码、归档 CRC/路径、版本及 SHA256 检查，以及包内启动验证，另记录在发布资产的校验报告中。仅标记实际通过的项目。

当前没有本版在原生 Windows 上的完整实机验收结果；不把 Linux 归档检查等同于 Windows GUI 或 CUDA 训练通过。所有模型、尺寸与硬件组合也未逐一完成真实数据训练。

## 下次更新方向

1. **填充与步幅编辑**：先在少量已验证卷积层上开放 padding / stride，显示预计和实测尺寸，定位下游冲突，提供预览后应用、可撤销的适配建议。
2. **模块与连线编辑**：逐步支持添加、复制、删除和连接模块，明确拼接与相加，核对通道、空间尺寸及检测步长；通过构建、训练和重载验收后再扩展模型范围。
3. **更直观的实验对比**：继续改进新手引导，记录修改，并逐步比较原始结构与修改结构的训练结果。

以上是后续方向，尚未在本版实现。当前核大小编辑仍自动配合填充保持输出尺寸，不把它描述为已支持独立 padding/stride 修改。
